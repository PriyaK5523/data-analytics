# Expenses Dashboard | FY 2025
📌 Project Overview
This project presents an interactive Expenses Dashboard developed using Microsoft Excel. It helps monitor expenses, compare budget allocation with actual spending, and analyze financial performance across departments and categories.

🎯 Objectives
- Track total expenses and budget utilization.
- Compare budget allocated vs. actual expenses.
- Analyze expenses by department and category.
- Monitor monthly spending trends.
- Identify payment method distribution.
- Enable interactive filtering using slicers.

🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- KPI Cards
- Conditional Formatting

📊 Dashboard Features
- Total Expenses
- Budget Allocated
- Budget Remaining
- Total Transactions
- Approval Rate
- Average Expense
- Department-wise Expense Analysis
- Category-wise Expense Distribution
- Monthly Expense Trend
- Budget vs Actual Comparison
- Payment Method Analysis
- Interactive Month and Department Filters

📁 Files Included
- `Expenses_Dashboard.xlsx` – Excel Dashboard
- `Expenses_Dataset.xlsx` – Source Dataset
- `README.md` – Project Documentation

📈 Key Insights
- Total Expenses: **144K**
- Budget Allocated: **173K**
- Budget Remaining: **30K**
- Approval Rate: **66.7%**
- Engineering department has the highest expenses.
- Bank Transfer and Credit Card are the most used payment methods.
